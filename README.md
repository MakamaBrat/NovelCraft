# maket_with_windows

Статический сайт, собранный в «Макет». Сборка не нужна.

## Как выложить на Vercel

**Через сайт:** распакуй архив, открой https://vercel.com/new и перетащи папку в окно (Framework Preset — Other).

**Через терминал:**

```
npm i -g vercel
cd папка-с-сайтом
vercel --prod
```

Чтобы обновить сайт, снова экспортируй проект из «Макета» и повтори деплой.
