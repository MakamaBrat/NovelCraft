# NovelCraft — конструктор визуальных новелл (v0.3)

Статический сайт, сборка не нужна. Данные хранятся в браузере (localStorage).

## Что уже работает
- Проекты: создать, открыть, удалить (при первом запуске есть демо-новелла «Лунная ночь»)
- Персонажи: имя, возраст, портрет (4 шт.)
- Сцены: фон (7 шт.), реплики от персонажа или рассказчика, варианты выбора с переходом в другую сцену, «дальше» без выбора
- Свои фоны и портреты: кнопка ＋ в выборе фона и при создании персонажа (картинки сжимаются автоматически)
- Переменные (вкладка «Ещё»): у варианта выбора можно задать «Меняет» (+/− к переменной) и «Нужно» (вариант виден только при достаточном значении). Значения видны в плеере
- Порядок сцен: первая в списке (★) — стартовая, остальные двигаются кнопкой ▲
- Экспорт проекта в .json и импорт обратно (резервная копия, перенос между устройствами)
- Плеер ▶: диалоги по тапу, выбор, концовка. Запуск со всего проекта или с текущей сцены

## Деплой на Vercel
Открой https://vercel.com/new и перетащи папку (Framework Preset — Other), либо `npx vercel --prod` в этой папке.
